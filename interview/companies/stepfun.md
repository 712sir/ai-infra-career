# 阶跃星辰（StepFun）

> 🥇 第一档 | 大模型独角兽，上海明星创业公司

## 面试特点
- **模型规模大**：千亿参数级大模型，Infra 挑战真实且硬核
- **技术氛围好**：创始团队来自微软亚研/MSRA，技术导向
- **高薪+期权**：创业公司薪资有竞争力，早期员工期权价值高
- **上海主场**：base 上海，对南方同学友好

## 核心方向

| 方向 | 说明 |
|------|------|
| **大模型推理框架** | 自研推理引擎，支持千亿参数模型的低延迟推理 |
| **分布式训练** | 千卡级训练集群的调度与优化 |
| **训练/推理加速** | CUDA kernel 优化、算子融合、编译优化 |
| **多模态 Infra** | 支持文本+图像+视频的多模态模型训练推理 |

## 高频考点
- CUDA kernel 优化（GEMM/FlashAttention）
- 大模型推理优化（KV Cache、PagedAttention、Speculative Decoding）
- 分布式训练（ZeRO、TP/PP、Megatron 风格）
- 系统设计（千卡集群的稳定性与容错）
- Python/C++ 混合编程
