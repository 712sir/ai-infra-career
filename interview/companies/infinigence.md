# 无问芯穹（Infinigence AI）

> 🥈 第二档 | 明星创业公司，异构算力调度方向

## 面试特点
- **算力调度视角**：不同于单卡优化，更关注多卡/多集群/异构芯片的统一调度
- **工程落地导向**：面试看重实际工程能力，不搞纯理论
- **创业氛围**：scope 大，一人多责，成长速度快
- **团队背景强**：核心成员来自清华/北大/中科院，跟高校合作紧密

## 核心方向

| 方向 | 说明 |
|------|------|
| **大模型推理引擎** | 自研推理框架，支持多种芯片（NVIDIA/昇腾/寒武纪）的统一推理 |
| **大模型训练基础设施** | 异构算力下的分布式训练调度与优化 |
| **异构算力调度** | 跨芯片厂商的统一算力池化管理，自动选择最优芯片类型 |
| **AI Compiler** | 多后端（CUDA/Ascend C/Bangbang）的统一编译优化 |

## 高频考点
- 推理引擎架构（PagedAttention、Continuous Batching）
- 多芯片适配经验（至少了解 2 种以上芯片生态）
- 分布式调度（Kubernetes/Volcano + GPU 调度）
- CUDA/Ascend C 算子开发
- 系统设计（大规模推理服务的架构）

## 面试风格
- 项目深挖为主，看实际动手能力
- 对创业公司文化认同（快速迭代、模糊边界）
- 相比大厂，bar 稍低但 scope 更大

## 准备重点
- MiniInfer/MiniMegatron 项目经验直接对口
- 了解华为昇腾、寒武纪等国产芯片的基本生态
- 关注异构计算趋势（oneAPI、OpenCL、SYCL）
