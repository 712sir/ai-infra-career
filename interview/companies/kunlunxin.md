# 昆仑芯（百度）

> 百度旗下 AI 芯片公司，原百度智能芯片及架构部独立

## 面试特点
- **百度体系内**：独立运营但与百度飞桨/PaddlePaddle 深度绑定
- **芯片+软件栈**：需要同时理解芯片架构和上层软件栈
- **国产替代方向**：与华为昇腾形成竞争，政策红利明显

## 核心方向

| 方向 | 说明 |
|------|------|
| **AI 芯片编译器** | 自研 XPU 编译器，将模型 IR 编译到昆仑芯指令集 |
| **推理 SDK** | 昆仑芯推理引擎，支持 CV/NLP/LLM 模型 |
| **PaddlePaddle 适配** | 飞桨框架在昆仑芯上的算子适配与性能优化 |
| **训练芯片** | 昆仑芯 3 代支持大模型训练 |

## 高频考点
- 编译原理基础（IR lowering、pass pipeline、graph optimization）
- AI 芯片架构（与 GPU 的异同）
- PaddlePaddle / PyTorch 框架基础
- C++ 工程能力
- CUDA 经验可迁移（概念相似）

## 面试风格
- 偏工程，编译器/芯片方向技术深度高
- 对芯片行业的热情和长期投入意愿有考察
- 北京/上海为主

## 准备重点
- 了解 AI 编译器基础（TVM/XLA/MLIR）
- CUDA kernel 优化经验可迁移
- PaddlePaddle 使用经验是加分项
