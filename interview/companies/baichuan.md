# 百川智能

> 🥈 大模型创业公司 | 王小川创立，技术氛围好

## 面试特点
- **搜狗技术基因**：创始团队 NLP 积累深厚，Infra 团队务实
- **模型迭代快**：需要 Infra 团队支撑快速模型迭代
- **北京主场**：base 北京，清华系背景

## 核心方向

| 方向 | 说明 |
|------|------|
| **大模型训练框架** | 自研训练框架，支撑百川大模型快速迭代 |
| **推理引擎** | 推理服务化，支持 API 和端侧部署 |
| **数据 Infra** | 大规模训练数据的清洗、去重、配比管理 |

## 高频考点
- 分布式训练（PyTorch DDP/FSDP、DeepSpeed）
- 推理引擎优化（类似 vLLM 架构）
- CUDA 基础（能写能调）
- 系统工程（数据管道、CI/CD、模型版本管理）

## 面试风格
- 偏工程务实，不太搞纯算法题
- 看重全栈能力（训练+推理+工程）
- 团队相对扁平，沟通直接

## 准备重点
- MiniInfer/MiniMegatron 项目经验对口
- 了解 NLP 领域大模型的基本架构
- 展示工程全栈能力
