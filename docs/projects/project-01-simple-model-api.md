# 项目 01 — 简单模型 API 部署

**时长:** 60 小时  
**难度:** 入门

---

## 项目概述

本项目的目标是使用 Flask 或 FastAPI 构建并部署一个为 ML 模型预测提供服务的 REST API。你需要从头搭建一个完整的模型服务：加载训练好的模型、暴露 `/predict` 端点接收推理请求、通过 Docker 进行容器化封装，并最终将服务部署到主流云平台（AWS、GCP 或 Azure）上。

通过完成本项目，你将掌握模型服务化的核心流程——从代码编写、容器化到云端部署的完整链路，为后续更复杂的 MLOps 基础设施项目打下坚实基础。

---

## 前置条件

- 模块 002：机器学习基础概念与 PyTorch/TensorFlow 入门
- 模块 003：REST API 设计与 HTTP 协议基础
- 模块 004：Docker 容器技术入门
- 模块 005：Linux 命令行与云平台基础

---

## 核心交付物

1. **REST API 服务** — 基于 Flask 或 FastAPI 的模型预测 API，含 `/predict` 端点，接收 JSON 输入并返回模型推理结果
2. **模型加载与推理代码** — 支持 PyTorch 或 TensorFlow 模型格式的加载器，含模型缓存与预热逻辑
3. **Dockerfile 与 docker-compose.yml** — 多阶段构建的 Docker 镜像定义，以及用于本地开发与测试的 Docker Compose 编排文件
4. **基础监控与日志** — 请求日志记录、推理延迟跟踪、错误率统计等基础可观测性实现
5. **云平台部署** — 将容器化服务部署到 AWS（ECS/EKS）、GCP（Cloud Run/GKE）或 Azure（ACI/AKS）任一平台
6. **项目 README** — 包含项目说明、架构图、API 文档、本地运行指南和部署步骤的完整文档

### 文件说明

- **README.md** — 项目的门面文档。需包含：项目简介、系统架构图（可使用 Mermaid 或图片）、API 端点文档（含 curl 示例）、环境要求、本地运行步骤、Docker 构建与运行命令、云平台部署指南、常见问题解答。
- **requirements.md** — 正式的需求规格说明书。需包含：功能需求（FR-001 到 FR-00N 逐条列出）、非功能需求（性能、安全、可用性）、API 接口规范（请求/响应 JSON Schema）、验收标准（每个需求可验证的通过条件）。
- **architecture.md** — 架构设计文档。需包含：系统上下文图、容器图、组件图、关键设计决策记录（ADR）、技术选型对比分析、数据流描述（从请求到响应的完整路径）。
- **.env.example** — 环境变量模板文件。列出所有可配置项并附带说明注释，如 `MODEL_PATH`、`MODEL_DEVICE`、`API_PORT`、`LOG_LEVEL`、`DB_URL`、云平台凭证变量等。不应包含真实凭证。
- **docker/Dockerfile** — 多阶段构建文件。Stage 1 安装构建依赖并复制源码，Stage 2 仅复制运行时依赖和构建产物，确保最终镜像体积最小化。需包含健康检查指令（HEALTHCHECK）。
- **docker/docker-compose.yml** — 本地开发编排文件。定义 `api` 服务（挂载源码目录实现热重载）和可选的 `db` 服务（PostgreSQL）。配置网络、卷挂载和环境变量注入。
- **src/README.md** — 源码目录说明。描述每个模块的职责、模块间的调用关系、开发约定（如日志格式、异常处理模式）、如何添加新模型支持。
- **src/app.py** — 应用程序入口。创建 FastAPI/Flask 实例，注册 `/predict` 路由（单条和批量）、`/health` 健康检查路由、`/metrics` 指标暴露路由。配置 CORS、请求限流、异常处理器等中间件。
- **src/config.py** — 配置管理模块。使用 Pydantic Settings（FastAPI）或 dataclass 从环境变量加载配置，提供类型校验和默认值。集中管理所有可配置参数，避免硬编码。
- **src/model_loader.py** — 模型加载器。负责加载序列化模型文件（.pt / .h5 / SavedModel），自动检测可用设备（CUDA/CPU），支持模型预热（执行一次空推理以触发 JIT 编译和 GPU 内核初始化），缓存推理会话。
- **tests/test_app.py** — API 功能测试。测试用例覆盖：`/health` 端点返回 200、`/predict` 端点接受合法输入并返回正确格式、输入校验拒绝非法数据、服务未就绪时的错误处理、并发请求下的线程安全性。
- **tests/test_model.py** — 模型推理测试。测试用例覆盖：模型加载成功、输入张量形状正确、输出张量形状符合预期、推理结果在合理范围内、空输入/极端值输入的边界行为、推理延迟基准测试。
