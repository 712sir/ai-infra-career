## 2.1 二分类问题（Binary Classification）

神经网络的开端——用逻辑回归来理解二分类。

### 定义

**二分类**：输出只有两种可能（0 或 1）。

**例子**：
- 判断图片中是否有猫 → 是（1）/ 否（0）
- 判断用户是否会点击广告 → 会（1）/ 不会（0）

### 符号约定（Notation）

| 符号 | 含义 | 维度 |
|------|------|:--:|
| `x` | 输入样本（单一） | `(n_x, 1)` |
| `X` | 整个训练集 | `(n_x, m)` |
| `y` | 标签（单一） | `{0, 1}` |
| `Y` | 所有标签 | `(1, m)` |
| `m` | 训练样本数量 | 标量 |
| `n_x` | 输入特征数量 | 标量 |
| `(x^(i), y^(i))` | 第 i 个样本 | — |

### 图像的特征表示

一副 64×64×3（RGB）的图片：
- 总像素数：64 × 64 × 3 = **12288**
- 将这 12288 个像素值展平成一列，即 `n_x = 12288`

## 2.2 逻辑回归（Logistic Regression）

**逻辑回归是一种用于二分类的算法。**

### 目标

给定输入 `x`，预测 `ŷ = P(y=1 | x)`——即 y=1 的概率。

**约束**：`0 ≤ ŷ ≤ 1`

### 模型公式

```
z = w^T·x + b      ← 线性部分
ŷ = σ(z)           ← Sigmoid 激活
```

其中：
- `w`：权重向量，`(n_x, 1)` → 决定每个特征的重要程度
- `b`：偏置，标量 → 相当于截距
- `σ`：Sigmoid 函数

### Sigmoid 函数

```
        1
σ(z) = ──────
       1 + e^(-z)
```

**形状**：S 型曲线

```
  1 ┤              ╭──────
    │            ╱
    │          ╱
0.5 ┤────●────
    │    ╱
    │  ╱
  0 ┤─╯
    └─────────────────
       -∞    0    +∞
```

**关键性质**：
- `σ(0) = 0.5`
- `σ(z) → 1` 当 `z → +∞`
- `σ(z) → 0` 当 `z → -∞`
- 导数：`σ'(z) = σ(z)(1 - σ(z))`

## 2.3 逻辑回归的代价函数（Logistic Regression Cost Function）

### 为什么不直接用误差平方？

如果使用平方误差 `L = ½(ŷ - y)²`：
- 配合 Sigmoid 后，损失函数**非凸**（non-convex）
- 非凸 = 有多个局部最优点 → 梯度下降可能找不到全局最优

### 损失函数（Loss Function）——单个样本

```
L(ŷ, y) = -[ y·log(ŷ) + (1-y)·log(1-ŷ) ]
```

**直观理解**：

| 情况 | y=1 时 | y=0 时 |
|------|--------|--------|
| 正确预测 | L = -log(1) = 0 ✓ | L = -log(1) = 0 ✓ |
| 错误预测 | L = -log(0) → +∞ ✗ | L = -log(0) → +∞ ✗ |

- 预测越精准，L 越小（接近 0）
- 预测越离谱，L 越大（趋向无穷）→"惩罚"错误

### 代价函数（Cost Function）——整个训练集

```
        1   m
J(w,b) = ──  Σ  L(ŷ^(i), y^(i))
        m  i=1
```

代价函数 = 所有样本损失的平均值。

**性质**：
- **凸函数**（convex）→ 只有一个全局最低点
- 可以用梯度下降找到最优的 `w` 和 `b`

## 2.4 梯度下降法（Gradient Descent）

**目标**：找到使 `J(w, b)` 最小的 `w` 和 `b`。

### 直观比喻

你站在山顶（随机初始点），蒙着眼睛，每次迈步都往脚下最陡的方向走，最终到达山谷（最低点）。

### 更新规则

```
w := w - α · ∂J/∂w      ← 重复执行，直到收敛
b := b - α · ∂J/∂b
```

其中：
- `α`（alpha）：**学习率**（learning rate），控制每步多大
- `∂J/∂w`：J 对 w 的**偏导数**（梯度方向）
- `:=`：赋值操作（不是等号）

### 学习率的作用

| α 太大 | α 太小 | α 合适 |
|:--:|:--:|:--:|
| 跳来跳去，可能不收敛 | 收敛太慢 | 稳步下降 |

### 计算图（Computation Graph）

**把复杂公式拆成一步步的计算**，这就是前向传播和反向传播的基础。

```
J(a, b, c) = 3(a + bc)

拆解：
  u = b × c    →  v = a + u    →  J = 3v

计算梯度（反向）：
  dJ/dv = 3
  dJ/da = dJ/dv · dv/da = 3 × 1 = 3
  dJ/db = dJ/dv · dv/du · du/db = 3 × 1 × c
  dJ/dc = dJ/dv · dv/du · du/dc = 3 × 1 × b
```

**这就是反向传播的本质——链式法则！**

## 2.5 逻辑回归的梯度下降（Logistic Regression Gradient Descent）

### 对一个样本的梯度推导

前向传播：
```
z = w^T·x + b
ŷ = a = σ(z)
L = -(y·log(a) + (1-y)·log(1-a))
```

反向传播：
```
da = dL/da = -y/a + (1-y)/(1-a)
dz = dL/dz = a - y           ← 推导结果极其简洁！
dw = dz · x
db = dz
```

### 对 m 个样本

```
        1   m
dw =    ──  Σ  x^(i) · (a^(i) - y^(i))
        m  i=1

        1   m
db =    ──  Σ  (a^(i) - y^(i))
        m  i=1
```

梯度下降更新：
```
w := w - α · dw
b := b - α · db
```

### 伪代码（一次梯度下降）

```python
J = 0; dw = zeros(n_x); db = 0

for i in range(m):
    z^(i) = w^T · x^(i) + b
    a^(i) = σ(z^(i))
    J += -(y^(i)·log(a^(i)) + (1-y^(i))·log(1-a^(i)))

    dz^(i) = a^(i) - y^(i)
    dw += x^(i) · dz^(i)
    db += dz^(i)

J /= m; dw /= m; db /= m

w := w - α·dw
b := b - α·db
```

> **问题**：for 循环在 Python 中很慢！需要**向量化**。

## 2.6 向量化（Vectorization）

**核心原则**：能用矩阵运算就不用 for 循环。

### 性能对比

| 方式 | 速度 | 原因 |
|------|:--:|------|
| 显式 for 循环 | 慢 | Python 逐行解释执行 |
| 向量化（numpy） | 快 100-300 倍 | 底层调用 BLAS/GPU 并行 |

```python
# 慢：for 循环
z = 0
for i in range(n_x):
    z += w[i] * x[i]
z += b

# 快：向量化（numpy）
z = np.dot(w.T, x) + b
```

**numpy 为什么快？**
- CPU 的 SIMD 指令（单指令多数据）→ 一条指令同时处理多组数据
- GPU 天生并行 → 上千个核同时算
- BLAS（基础线性代数子程序）→ 高度优化的矩阵运算库

### 逻辑回归的向量化实现

```python
# 一次梯度下降（无 for 循环版本）
Z = np.dot(w.T, X) + b           # (1, m) → 所有样本同时算
A = sigmoid(Z)                   # 所有样本的预测值
J = -np.mean(Y * np.log(A) + (1-Y) * np.log(1-A))  # 代价

dZ = A - Y                       # (1, m)
dw = np.dot(X, dZ.T) / m         # (n_x, 1)
db = np.sum(dZ) / m              # 标量

w -= alpha * dw
b -= alpha * db
```

> 11 行 for 循环缩减为 7 行 numpy。速度快 100+ 倍。

### 广播（Broadcasting）

**不同形状的数组进行运算时，numpy 自动扩展维度。**

```python
# (m, n) 矩阵 + (1, n) 行向量
# numpy 自动将 (1, n) 复制 m 行 → (m, n)
A = np.array([[1,2,3],
              [4,5,6]])     # (2, 3)
b = np.array([100, 200, 300])  # (3,)
result = A + b              # b 被广播为 (2, 3)
# [[101, 202, 303],
#  [104, 205, 306]]
```

**规则**：从最后一维向前比对，维度相等或其中一个是 1 → 可广播。

### 消除秩为 1 的数组

```python
# ❌ 不要这样写（shape 不明确，易出 bug）
a = np.random.randn(5)      # shape: (5,) ← 秩为1

# ✅ 明确指定维度
a = np.random.randn(5, 1)   # shape: (5, 1) ← 列向量
a = np.random.randn(1, 5)   # shape: (1, 5) ← 行向量

# 随时检查
assert(a.shape == (5, 1))
a = a.reshape(5, 1)         # 修正不确定的 shape
```

## 2.8 逻辑回归代价函数的数学解释（可选）

### 为什么是这个损失函数？

**从概率角度**：

在给定 `x` 的条件下，`y` 的条件概率：

```
P(y=1 | x) = ŷ            → 模型预测为"是"的概率
P(y=0 | x) = 1 - ŷ        → 模型预测为"否"的概率
```

合并为一个公式：

```
P(y | x) = ŷ^y · (1-ŷ)^(1-y)
```

- 当 `y=1`：`P = ŷ`  ← 正确
- 当 `y=0`：`P = 1-ŷ` ← 正确

**取 log**（对数不改变单调性，但将乘除变加减）：

```
log P(y|x) = y·log(ŷ) + (1-y)·log(1-ŷ)
```

**加负号**（最大化概率 = 最小化负对数概率）：

```
L(ŷ, y) = -[y·log(ŷ) + (1-y)·log(1-ŷ)]
```

### 最大似然估计（MLE）

整个训练集的**似然**（在所有 `(x, y)` 下同时发生的概率）：

```
    m
P = Π  P(y^(i) | x^(i))
   i=1
```

取 log + 取负 + 除以 m：

```
        1   m
J =    -─  Σ [y^(i)·log(ŷ^(i)) + (1-y^(i))·log(1-ŷ^(i))]
        m  i=1
```

**这正是"交叉熵损失"**，等价于**最大似然估计**取负。

## 编程练习核心代码

```python
import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def initialize_with_zeros(dim):
    w = np.zeros((dim, 1))
    b = 0
    return w, b

def propagate(w, b, X, Y):
    m = X.shape[1]

    # 前向传播
    A = sigmoid(np.dot(w.T, X) + b)     # (1, m)
    cost = -np.mean(Y * np.log(A) + (1-Y) * np.log(1-A))

    # 反向传播
    dw = np.dot(X, (A - Y).T) / m       # (dim, 1)
    db = np.sum(A - Y) / m

    return dw, db, cost

def optimize(w, b, X, Y, num_iterations, learning_rate):
    for i in range(num_iterations):
        dw, db, cost = propagate(w, b, X, Y)
        w -= learning_rate * dw
        b -= learning_rate * db
    return w, b

def predict(w, b, X):
    A = sigmoid(np.dot(w.T, X) + b)
    return (A > 0.5).astype(int)
```
