## 3.1 神经网络概览（Neural Networks Overview）

### 从逻辑回归到神经网络

第二周的逻辑回归本质上是**一个神经元**：

```
x₁ ──→
x₂ ──→  σ(wᵀx + b)  ──→ ŷ
x₃ ──→
```

本周把它扩展成**含一个隐藏层的浅层神经网络**：

```
x₁ ──→ [a₁] ──┐
x₂ ──→ [a₂] ──┼──→ ŷ
x₃ ──→ [a₃] ──┘
 ↑       ↑        ↑
输入层  隐藏层   输出层
```

**关键区别**：逻辑回归只有输入→输出一步计算；神经网络在中间多了隐藏层，每一层都在学习更复杂的特征组合。

---

## 3.2 神经网络表示（Neural Network Representation）

### 层的命名

```
输入层        隐藏层        输出层
 (第0层)      (第1层)      (第2层)

  x₁  ──→  a₁^[1]  ──┐
  x₂  ──→  a₂^[1]  ──┼──→  a^[2] = ŷ
  x₃  ──→  a₃^[1]  ──┘
  x₄  ──→  a₄^[1]  ──→  (可能还有更多)
```

### 符号约定

| 符号 | 含义 | 示例 |
|------|------|------|
| `n^[0]` | 输入层单元数 | `n^[0] = n_x = 3` |
| `n^[1]` | 隐藏层单元数 | `n^[1] = 4` |
| `n^[2]` | 输出层单元数 | `n^[2] = 1` |
| `a^[l]` | 第 l 层的激活值 | `a^[0] = x`, `a^[2] = ŷ` |
| `W^[l]` | 第 l 层的权重矩阵 | `W^[1]` 形状 `(4, 3)` |
| `b^[l]` | 第 l 层的偏置向量 | `b^[1]` 形状 `(4, 1)` |

> **注意**：上标 `[l]` 表示层号，`(i)` 表示第 i 个样本。这是两个不同的括号。

## 3.3 计算神经网络的输出（Computing a Neural Network's Output）

### 单个隐藏层的前向传播

**隐藏层（第 1 层）**：

```
z^[1] = W^[1] · x + b^[1]        ← 线性部分
a^[1] = σ(z^[1])                  ← 激活（Sigmoid）
```

其中：
- `W^[1]`：`(n^[1], n^[0])` 即 `(4, 3)`
- `b^[1]`：`(n^[1], 1)` 即 `(4, 1)`
- `z^[1]`：`(n^[1], 1)` 即 `(4, 1)`

**输出层（第 2 层）**：

```
z^[2] = W^[2] · a^[1] + b^[2]
a^[2] = σ(z^[2]) = ŷ
```

其中 `W^[2]` 形状 `(1, 4)`，`b^[2]` 形状 `(1, 1)`。

### 直观理解

**隐藏层的每个神经元做了什么？**

把每个隐藏单元看作一个小的"逻辑回归"：
- 第 1 个隐藏单元：`a₁^[1] = σ(W₁·x + b₁)`——它自己学到了一组权重
- 第 2 个隐藏单元：`a₂^[1] = σ(W₂·x + b₂)`——它学到了另一组权重

然后输出层把隐藏单元的"发现"组合起来做最终预测。

## 3.4 向量化多个样本（Vectorizing Across Multiple Examples）

### 循环版（慢）

```python
# 对每个样本逐个算——m 次循环
for i in range(m):
    z1 = np.dot(W1, x[:, i]) + b1       # (4, 1)
    a1 = sigmoid(z1)                     # (4, 1)
    z2 = np.dot(W2, a1) + b2            # (1, 1)
    a2[:, i] = sigmoid(z2)              # 1个预测值
```

### 向量化版（快 100+ 倍）

```python
# 一次性算全部 m 个样本
Z1 = np.dot(W1, X) + b1                 # (4, m)
A1 = sigmoid(Z1)                        # (4, m)
Z2 = np.dot(W2, A1) + b2                # (1, m)
A2 = sigmoid(Z2)                        # (1, m) —— 全部预测
```

这里利用了 numpy 的**广播**：`b1` 是 `(4, 1)`，自动扩展为 `(4, m)` 加到每一列。

### 维度检查表

| 矩阵 | 形状 |
|------|:--:|
| `X` | `(n_x, m)` |
| `W^[1]` | `(n^[1], n_x)` |
| `b^[1]` | `(n^[1], 1)` |
| `Z^[1]`, `A^[1]` | `(n^[1], m)` |
| `W^[2]` | `(n^[2], n^[1])` |
| `b^[2]` | `(n^[2], 1)` |
| `Z^[2]`, `A^[2]` | `(n^[2], m)` |

> **自查口诀**：`W^[l]` 的行数是当前层单元数，列数是上一层单元数。`Z^[l]` 的行数是当前层单元数，列数是样本数。

## 3.5 激活函数（Activation Functions）

### 四种常用激活函数

| 函数 | 公式 | 输出范围 | 特点 |
|------|------|:--:|------|
| **Sigmoid** | `1/(1+e^(-z))` | (0, 1) | 输出层二分类用，隐藏层不用 |
| **tanh** | `(e^z - e^(-z))/(e^z + e^(-z))` | (-1, 1) | 比 Sigmoid 好——零中心化 |
| **ReLU** | `max(0, z)` | [0, +∞) | **隐藏层默认首选**——快、不饱和 |
| **Leaky ReLU** | `max(0.01z, z)` | (-∞, +∞) | 解决 ReLU 的"死亡神经元"问题 |

### 形状速览

```
Sigmoid         tanh            ReLU           Leaky ReLU
  ╭──            ╱              │  ╱            │  ╱
 ╱              ╱               │ ╱             │ ╱
╱              ╱                │╱              │╱
─────        ─────            ──●──           ──●──
              ╲                ╱│              ╱│
               ╲              ╱ │             ╱ │
                ╲                               
```

### 选择策略

```
隐藏层激活函数：
  ├─ ReLU —— 首选，90% 的情况下直接用
  ├─ tanh —— 次选（零中心化，但两端饱和）
  └─ Leaky ReLU —— 当 ReLU 出现死亡神经元时

输出层激活函数：
  ├─ Sigmoid —— 二分类（输出 0~1 概率）
  ├─ Linear —— 回归（输出任意值）
  └─ Softmax —— 多分类
```

## 3.6 为什么需要非线性激活函数

**如果所有层都用线性激活（或不用激活）**：

```
a^[1] = z^[1] = W^[1]x + b^[1]
a^[2] = z^[2] = W^[2]a^[1] + b^[2]
       = W^[2](W^[1]x + b^[1]) + b^[2]
       = (W^[2]W^[1])x + (W^[2]b^[1] + b^[2])
       = W'·x + b'                    ← 还是线性的！
```

无论多少层，线性变换的复合**仍是线性变换**。隐藏层形同虚设。

**结论**：
- 隐藏层**必须用非线性**激活函数
- 输出层回归问题可以用线性激活（即不用激活）
- 输出层二分类必须用 Sigmoid

## 3.7 激活函数的导数

| 函数 | 导数 | 记忆方式 |
|------|------|------|
| **Sigmoid** `g(z)` | `g'(z) = g(z)(1 - g(z))` | 自身 × (1 - 自身) |
| **tanh** `g(z)` | `g'(z) = 1 - g(z)²` | 1 - 自身² |
| **ReLU** | `g'(z) = 1` (z>0), `0` (z<0) | 正数过，负数不过 |
| **Leaky ReLU** | `g'(z) = 1` (z>0), `0.01` (z<0) | 正数全过，负数漏一点 |

> 代码里你不需要手写导数——框架（PyTorch/TF）的 autograd 自动求。

## 3.8 神经网络的梯度下降

### 参数

```
参数：W^[1], b^[1], W^[2], b^[2]
总维度：n^[1]×(n_x+1) + n^[2]×(n^[1]+1)
```

### 一次梯度下降的步骤

```
1. 前向传播：
   Z^[1] = W^[1]X + b^[1]
   A^[1] = g^[1](Z^[1])
   Z^[2] = W^[2]A^[1] + b^[2]
   A^[2] = g^[2](Z^[2]) = ŷ
   J = cost(ŷ, Y)

2. 反向传播（计算梯度）：
   dZ^[2] = A^[2] - Y
   dW^[2] = (1/m) · dZ^[2] · A^[1]ᵀ
   db^[2] = (1/m) · sum(dZ^[2])
   dZ^[1] = W^[2]ᵀ · dZ^[2] * g'^[1](Z^[1])    ← 链式法则
   dW^[1] = (1/m) · dZ^[1] · Xᵀ
   db^[1] = (1/m) · sum(dZ^[1])

3. 更新参数：
   W^[1] := W^[1] - α·dW^[1]
   b^[1] := b^[1] - α·db^[1]
   W^[2] := W^[2] - α·dW^[2]
   b^[2] := b^[2] - α·db^[2]
```

### 反向传播的直观理解

反向传播就是**链式法则的系统化应用**——从输出层的误差开始，逐层往回传，每一步都在问："这个参数对最终误差贡献了多少？"

#### 从一个数字开始（最简单的神经网络）

```
x=3  ──→  z = w·x  ──→  ŷ = σ(z)  ──→  L = (ŷ - y)²
            ↑                    ↑              ↑
        w 是参数              Sigmoid         损失
```

**你的真正目标**：`w` 变一点点，`L` 会怎么变？即 `dL/dw`。

#### 链式法则——像剥洋葱，一层一层来

`w` 和 `L` 中间隔着 `z` 和 `ŷ`，没法直接求导。但可以沿着链条一步一步走：

```
dL/dw = (dL/dŷ) × (dŷ/dz) × (dz/dw)
         ↑           ↑         ↑
      ŷ对L的影响   z对ŷ的影响  w对z的影响
```

代入具体数字——`y=1`, `w=2`, `x=3`：

```
① 前向（算出每个值）：
   z = w·x = 2×3 = 6
   ŷ = σ(6) = 1/(1+e⁻⁶) ≈ 0.998     ← 预测接近 1，还不错
   L = (0.998 - 1)² ≈ 0.000004

② 反向（从后往前算梯度）：
   dL/dŷ = 2(ŷ - y) = 2(0.998 - 1) = -0.004  ← "ŷ 变大，L 变小"（因为 ŷ<y）
   dŷ/dz = σ(z)×(1-σ(z)) = 0.002              ← "Sigmoid 在 z=6 已经很平"
   dz/dw = x = 3                               ← "w 变大 1，z 就变大 3"

③ 乘起来：
   dL/dw = (-0.004) × 0.002 × 3 ≈ -0.000024   ← 负号→w 应该变大

④ 更新：
   w := w - α·dL/dw = 2 + 0.00000024           ← w 微微增大
```

#### 扩展到两个隐藏单元——"责任分配"

```
x ──→ z₁ = w₁x ──→ a₁ = σ(z₁) ──┐
  │                                ├──→ z_out = v₁a₁ + v₂a₂ ──→ ŷ ──→ L
  └──→ z₂ = w₂x ──→ a₂ = σ(z₂) ──┘
```

要算 `dL/dw₁`，链更长：

```
dL/dw₁ = (dL/dŷ) × (dŷ/dz_out) × (dz_out/da₁) × (da₁/dz₁) × (dz₁/dw₁)
          ①          ②             ③             ④           ⑤
```

**第三步是理解反向传播的关键**：

```
z_out = v₁a₁ + v₂a₂
→  dz_out/da₁ = v₁     ← w₁ 的梯度里乘着 v₁！
```

**直觉**：如果输出层权重 `v₁` 很大，意味着第一个隐藏单元对最终结果贡献大 → `w₁` 的梯度也大 → `w₁` 被大幅更新。反过来如果 `v₁≈0`，这个隐藏单元基本不参与输出 → `w₁` 几乎不动。

> **这就是"反向传播"的本质：输出层把"责任"按权重往回分配。谁对最终误差贡献大，谁的参数就多调一点。**

#### 总结：一张图记住

```
前向：x → w·x → σ → a → v·a → σ → ŷ → L
                                              ↑
反向：  dw ←──  ×  ←──  ×  ←──  ×  ←──  ×  ←┘
        ↑         ↑         ↑         ↑
    dz/dw=x   da/dz=...  dz/da=v   dL/dŷ

每一步 = 从后面传来的"累计梯度" × 当前层的"局部导数"
```

层数再多也一样——每层只管自己的局部导数，乘上后面传来的梯度，然后继续往前面传。

现在回头看矩阵版公式：

```
输出层：dZ^[2] = ŷ - y        ← "预测差了多少"
   ↓
隐藏层：dZ^[1] = W^[2]ᵀ·dZ^[2] * g'^[1]  ← "这层的每个单元差了多少"
```

`W^[2]ᵀ` 就是上面说的"权重越大，传回去的梯度越大"的矩阵版——每一列都是输出层对对应隐藏单元的责任分配。

## 3.9 随机初始化（Random Initialization）

### 为什么不能全零初始化

逻辑回归可以把 `w` 初始化为零（只有一个神经元，没问题）。

**但神经网络不行！**

```python
# ❌ 如果 W^[1] 和 b^[1] 全为 0
W1 = np.zeros((4, 3))  # 第一层
# → a₁^[1] = a₂^[1] = a₃^[1] = a₄^[1] 全部相等
# → dW 的每一行也相等
# → 所有隐藏单元做一模一样的事——完全冗余
```

这叫**对称性破坏失败**——所有隐藏单元学到的特征完全相同。

### 正确做法

```python
# ✅ 用小的随机数打破对称
W1 = np.random.randn(4, 3) * 0.01

# b 可以初始化为 0——在 W 随机时不会引起对称问题
b1 = np.zeros((4, 1))

W2 = np.random.randn(1, 4) * 0.01
b2 = np.zeros((1, 1))
```

### 为什么乘以 0.01

- 如果 `W` 太大 → `z` 很大 → Sigmoid/tanh 梯度趋近 0 → 收敛极慢
- 如果 `W` 太小 → 网络退化为线性模型（tanh 在 0 附近近似线性）
- `0.01` 是一个经验性的折中值

> 深度学习里还有更好的初始化方法（He 初始化、Xavier 初始化），后面课程会讲。

## 3.10 完整实现（向量化版）

```python
import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def layer_sizes(X, Y):
    n_x = X.shape[0]
    n_h = 4                          # 隐藏层单元数（超参数）
    n_y = Y.shape[0]
    return (n_x, n_h, n_y)

def initialize_parameters(n_x, n_h, n_y):
    np.random.seed(2)
    W1 = np.random.randn(n_h, n_x) * 0.01
    b1 = np.zeros((n_h, 1))
    W2 = np.random.randn(n_y, n_h) * 0.01
    b2 = np.zeros((n_y, 1))

    return {"W1": W1, "b1": b1, "W2": W2, "b2": b2}

def forward_propagation(X, params):
    W1, b1 = params["W1"], params["b1"]
    W2, b2 = params["W2"], params["b2"]

    Z1 = np.dot(W1, X) + b1
    A1 = np.tanh(Z1)                       # 隐藏层用 tanh
    Z2 = np.dot(W2, A1) + b2
    A2 = sigmoid(Z2)                       # 输出层用 sigmoid

    return {"Z1": Z1, "A1": A1, "Z2": Z2, "A2": A2}

def compute_cost(A2, Y):
    m = Y.shape[1]
    cost = -np.mean(Y * np.log(A2) + (1 - Y) * np.log(1 - A2))
    return np.squeeze(cost)

def backward_propagation(params, cache, X, Y):
    m = X.shape[1]
    W2 = params["W2"]

    A1, A2 = cache["A1"], cache["A2"]

    dZ2 = A2 - Y
    dW2 = np.dot(dZ2, A1.T) / m
    db2 = np.sum(dZ2, axis=1, keepdims=True) / m

    dZ1 = np.dot(W2.T, dZ2) * (1 - np.power(A1, 2))  # tanh 导数 = 1 - tanh²
    dW1 = np.dot(dZ1, X.T) / m
    db1 = np.sum(dZ1, axis=1, keepdims=True) / m

    return {"dW1": dW1, "db1": db1, "dW2": dW2, "db2": db2}

def update_parameters(params, grads, learning_rate=1.2):
    params["W1"] -= learning_rate * grads["dW1"]
    params["b1"] -= learning_rate * grads["db1"]
    params["W2"] -= learning_rate * grads["dW2"]
    params["b2"] -= learning_rate * grads["db2"]
    return params

def nn_model(X, Y, n_h, num_iterations=10000, print_cost=False):
    n_x = X.shape[0]
    n_y = Y.shape[0]

    params = initialize_parameters(n_x, n_h, n_y)

    for i in range(num_iterations):
        cache = forward_propagation(X, params)
        cost = compute_cost(cache["A2"], Y)
        grads = backward_propagation(params, cache, X, Y)
        params = update_parameters(params, grads)

        if print_cost and i % 1000 == 0:
            print(f"Cost after iteration {i}: {cost:.6f}")

    return params

def predict(params, X):
    cache = forward_propagation(X, params)
    return (cache["A2"] > 0.5).astype(int)
```

## 本周核心知识点总结

| 概念 | 一句话解释 |
|------|---------|
| **隐藏层** | 输入和输出之间的中间层，自动学习特征组合 |
| **激活函数** | 引入非线性——没有它多层=单层 |
| **ReLU** | `max(0,z)`——隐藏层默认首选，快且不饱和 |
| **tanh** | 比 Sigmoid 好（零中心化），但仍有饱和问题 |
| **前向传播** | 输入→隐藏层→输出层，逐层计算 |
| **反向传播** | 输出误差→链式法则→逐层回传梯度 |
| **随机初始化** | 小随机数打破对称性，`np.random.randn() * 0.01` |
| **全零初始化** | 隐藏层不行——所有单元学相同的特征 |
