## 1.2 什么是神经网络（What is a Neural Network?）

### 房价预测案例

以房价预测为例理解神经网络：

- **输入 x**：房屋面积（size）
- **输出 y**：房屋价格（price）
- **神经元**：接受 x，经过线性运算，输出 y

这就是最简单的神经网络——**单个神经元（单层网络）**。

**ReLU 函数**：修正线性单元（Rectified Linear Unit）
- 公式：`f(x) = max(0, x)`
- 作用：保证输出不会为负（价格不能为负）

### 多特征扩展

当加入更多特征（卧室数量、邮编、周边富裕程度等）：

```
[面积] ──→ [神经元] ──┐
[卧室] ──→ [神经元] ──┼──→ [神经元] ──→ 价格
[邮编] ──→ [神经元] ──┘
[富裕度] ──→ [神经元] ──→ [神经元] ──→ 价格
```

- 左侧输入层：每个神经元接收一个特征
- 中间隐藏层：自动组合特征
- 右侧输出层：给出最终预测

**核心思想**：神经网络不需要你手动设计特征组合，它会自己学习。

## 1.3 用神经网络进行监督学习（Supervised Learning with Neural Networks）

### 监督学习回顾

| 输入类型 | 输出类型 | 应用 | 网络类型 |
|---------|---------|------|---------|
| 房屋特征 | 价格 | 房地产 | 标准 NN |
| 广告 + 用户信息 | 是否点击（0/1） | 在线广告 | 标准 NN |
| 图像 | 物体类别 | 图像识别 | **CNN** |
| 音频 | 文字转录 | 语音识别 | **RNN** |
| 英文 | 中文 | 机器翻译 | **RNN / Transformer** |
| 图像 + 雷达 | 车辆位置 | 自动驾驶 | **混合架构** |

### 三大主流网络架构

| 架构 | 全称 | 擅长处理 | 典型应用 |
|------|------|---------|---------|
| **标准 NN** | Standard Neural Network | 结构化数据 | 房价预测、广告点击 |
| **CNN** | Convolutional Neural Network | 图像/视频 | 图像识别、目标检测 |
| **RNN** | Recurrent Neural Network | 序列数据 | 语音识别、机器翻译、时间序列 |

### 结构化数据 vs 非结构化数据

| 类型 | 定义 | 例子 |
|------|------|------|
| **结构化数据** | 有明确字段定义的表格型数据 | 数据库表、用户特征向量 |
| **非结构化数据** | 无固定格式的原始数据 | 图像、音频、文本、视频 |

> **关键趋势**：深度学习让计算机首次能有效理解非结构化数据，这改变了整个行业。

## 1.4 为什么深度学习会兴起（Why is Deep Learning Taking Off?）

### 三要素驱动

```
        性能
         ↑
         │                    ● 大型神经网络
         │                 ↗
         │              ↗
         │           ↗  ● 中型神经网络
         │        ↗
         │     ↗  ● 小型神经网络
         │  ↗
         │ ↗  ● 传统机器学习
         └──────────────────────→ 数据量
```

**结论**：当数据量很大时，大网络性能远超传统方法和小网络。

### 推动深度学习的三个因素

| 因素 | 说明 |
|------|------|
| **数据（Data）** | 数字化产生了海量数据（用户行为、图像、文本） |
| **算力（Computation）** | GPU 让大规模矩阵运算成为可能 |
| **算法（Algorithms）** | 关键创新使训练更快（如 ReLU 替代 Sigmoid、更好的初始化） |

### 算法创新的重要性

**Sigmoid → ReLU 的转变**：

- Sigmoid 在两端梯度趋于 0，导致"梯度消失"，训练极慢
- ReLU 的梯度始终为 0 或 1，梯度下降快得多
- 这个简单改变让训练时间从数周缩短到数小时

> **本质**：深度学习的"深度"意味着多层非线性变换，每一层学习不同抽象层次的特征。

### 迭代速度的重要性

- 想法 → 代码实现 → 实验 → 看结果 的循环越快越好
- 好的工具/框架（TensorFlow、PyTorch）大幅缩短这个周期
- GPU 让实验从数天缩短到数分钟

## 本周核心知识点总结

| 概念 | 一句话解释 |
|------|---------|
| **神经网络** | 模仿人脑神经元连接的计算模型，由输入层→隐藏层→输出层组成 |
| **ReLU** | `max(0, x)`，最常用的激活函数，解决梯度消失问题 |
| **监督学习** | 给定输入 x 和标签 y，学习从 x 到 y 的映射 |
| **CNN** | 卷积神经网络，擅长图像处理 |
| **RNN** | 循环神经网络，擅长序列数据 |
| **结构化/非结构化数据** | 数据库表 vs 图像/音频/文本 |
| **深度学习三要素** | 大数据 + GPU 算力 + 算法创新 |
