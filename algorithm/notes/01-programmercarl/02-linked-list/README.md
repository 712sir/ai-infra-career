## LC 203. 移除链表元素

三解法：直接删除 / 虚拟头节点 / 递归

**关键收获**：

1. **虚拟头节点 (Dummy Head) 是最重要的链表技巧**
   - 问题：删除头节点和删除中间节点的逻辑不一致
   - 解决：加一个虚拟头节点，所有节点变成"中间节点"，统一处理
   - 做法：`dummy = ListNode(0, head)`，最后返回 `dummy.next`

2. **删除头节点时用 while 不是 if**
   - 可能连续多个头节点都需要删除
   - `while head and head.val == val: head = head.next`

3. **Python 注意事项**
   - 没有 NULL，用 `None`
   - 类方法递归调用必须加 `self.`

## 链表技巧速查

| 技巧 | 适用场景 | 关键点 |
|------|----------|--------|
| 虚拟头节点 | 可能修改头节点时 | `dummy.next = head`，最后返回 `dummy.next` |
| 快慢指针 | 找中点/环检测/倒数第K | 快指针先走，或者快指针每次两步 |
| 双指针换轨 | 链表相交 | A 走完走 B，B 走完走 A |
| 头插法 | 反转链表 | 逐个摘下节点插到头部 |
| 递归 | 链表反转/删除 | 从后往前处理，简洁但有栈开销 |
| 双向遍历 | 双链表查/插/删 | `size>>1` 判断从头还是从尾走，O(min(index, N-index)) |

## LC 707. 设计链表

四实现：单链表 + 双链表（C++/Python 各两版）

### 关键收获

1. **单链表虚拟头节点**：所有操作统一处理，不需要特判 head
2. **双链表哨兵节点**：`sentinel->next = sentinel->pre = sentinel` 循环引用，省去判空
3. **双向遍历优化**：`index < size>>1` → 从头走，否则从尾走 → O(min(index, N-index))

### 🔥 常见错误（Python）

| 错误 | 现象 | 原因 | 修复 |
|------|------|------|------|
| `_init_` 单下划线 | 构造不生效 | `__init__` 才是 dunder 方法 | 前后各两个下划线 |
| 缩进不一致 | `IndentationError` | if 块内多/少空格 | 统一用 4 空格倍数 |
| `self.size+=1` | PEP 8 风格警告 | 运算符两侧缺空格 | `self.size += 1` |

### 🔥 常见错误（C++）

| 错误 | 现象 | 原因 | 修复 |
|------|------|------|------|
| `delete` 后不置空 | 野指针 | delete 后指针值为随机地址 | `tmp = nullptr` |
| `while(--index)` | 死循环 | 先减再判断，边界不对 | `while(index--)` |
| `for` 循环边界 | size/index 关系混乱 | 没想清楚第几个节点 | 画图标注 cur 停在哪 |
