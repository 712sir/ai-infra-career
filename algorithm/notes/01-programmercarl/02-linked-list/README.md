## LC 203. 移除链表元素

三解法：直接删除 / 虚拟头节点 / 递归

**关键收获**：

1. **虚拟头节点 (Dummy Head) 是最重要的链表技巧**
   - 问题：删除头节点和删除中间节点的逻辑不一致
   - 解决：加一个虚拟头节点，所有节点变成"中间节点"，统一处理
   - 做法：`dummy = ListNode(0, head)`，最后返回 `dummy.next`

2. **删除头节点时用 while 不是 if**
   - 可能连续多个头节点都需要删除
   - `while head and head.val == val: head = head.next`

3. **Python 注意事项**
   - 没有 NULL，用 `None`
   - 类方法递归调用必须加 `self.`

## 链表技巧速查

| 技巧 | 适用场景 | 关键点 |
|------|----------|--------|
| 虚拟头节点 | 可能修改头节点时 | `dummy.next = head`，最后返回 `dummy.next` |
| 快慢指针 | 找中点/环检测/倒数第K | 快指针先走，或者快指针每次两步 |
| 双指针换轨 | 链表相交 | A 走完走 B，B 走完走 A |
| 头插法 | 反转链表 | 逐个摘下节点插到头部 |
| 递归 | 链表反转/删除 | 从后往前处理，简洁但有栈开销 |
