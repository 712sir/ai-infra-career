# 206. 反转链表

> [LeetCode 206](https://leetcode.cn/problems/reverse-linked-list/) | 核心第 3 题 | 三种方法

## 核心思路

反转链表的关键操作只有两步，重复到链表末尾：

```
cur->next = pre;    // ① 当前节点指向前一个
pre = cur;          // ② pre 和 cur 同步前进
cur = tmp;
```

用 `tmp` 保存下一个节点，防止断链后找不回来。

---

## 方法一：双指针法

```
输入:  1 → 2 → 3 → 4 → 5 → NULL

过程:
pre=NULL  cur=1     tmp=2 → 1→NULL         pre=1  cur=2
pre=1     cur=2     tmp=3 → 2→1→NULL        pre=2  cur=3
pre=2     cur=3     tmp=4 → 3→2→1→NULL      pre=3  cur=4
...

输出:  5 → 4 → 3 → 2 → 1 → NULL
```

```cpp
ListNode* reverseList(ListNode* head) {
    ListNode* tmp;
    ListNode* cur = head;
    ListNode* pre = nullptr;
    while (cur) {
        tmp = cur->next;   // 保存下一个，防止断链
        cur->next = pre;   // 反转指向
        pre = cur;         // pre 前进
        cur = tmp;         // cur 前进
    }
    return pre;            // pre 指向新链表的头
}
```

```python
def reverseList(self, head):
    cur, pre = head, None
    while cur:
        tmp = cur.next
        cur.next = pre
        pre = cur
        cur = tmp
    return pre
```

## 方法二：递归法（从前往后）

和双指针法完全相同的逻辑，只是用递归代替 while 循环。

```
reverse(pre, cur):
  cur==NULL → 返回 pre（走到末尾了）
  否则 → 保存 cur->next → 反转 cur->next = pre → 递归(cur, tmp)
```

```cpp
ListNode* reverse(ListNode* pre, ListNode* cur) {
    if (cur == nullptr) return pre;
    ListNode* tmp = cur->next;
    cur->next = pre;
    return reverse(cur, tmp);
}
ListNode* reverseList(ListNode* head) {
    return reverse(nullptr, head);
}
```

```python
def reverse(self, cur, pre):
    if cur is None:
        return pre
    tmp = cur.next
    cur.next = pre
    return self.reverse(tmp, cur)

def reverseList(self, head):
    return self.reverse(head, None)
```

## 方法三：递归法（从后往前）

先递归到链表末尾，然后在**回溯**过程中逐层反转。

```
reverseList(1→2→3→4→5→NULL)
  递归到最深处: reverseList(5) → head(5).next==NULL, return 5
  回溯到 4:    4→5→NULL
              last = 5（递归返回的新头）
              4.next.next = 4  →  5→4
              4.next = NULL    →  5→4→NULL
  回溯到 3:    3→4→NULL
              last = 5
              3.next.next = 3  →  4→3
              3.next = NULL    →  5→4→3→NULL
  ...
  最终:       5→4→3→2→1→NULL
```

```cpp
ListNode* reverseList(ListNode* head) {
    if (head == nullptr) return nullptr;   // 空链表
    if (head->next == nullptr) return head; // 到末尾了，返回作为新头

    ListNode* last = reverseList(head->next); // 递归到末尾
    head->next->next = head;  // 后一个节点指回自己
    head->next = nullptr;     // 自己的 next 置空
    return last;              // 新头一直传回去
}
```

```python
def reverseList(self, head):
    if head is None:
        return None
    if head.next is None:
        return head

    last = self.reverseList(head.next)
    head.next.next = head
    head.next = None
    return last
```

---

## 关键点

| 要点 | 说明 |
|------|------|
| 临时保存 `tmp` | 改 `cur->next` 前必须保存，否则后面的节点找不到了 |
| 返回值是 `pre` 不是 `cur` | 循环结束时 `cur==NULL`，`pre` 才是最后一个有效节点 |
| 递归从后往前 | 回溯阶段反转，最深处返回的 `last` 一路传回就是新头 |
| 空链表和单节点 | 边界条件：`head==NULL` 或 `head->next==NULL` |
